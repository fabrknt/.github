# FABRKNT

**Tools that leave a checkable record of operational actions on onchain financial systems.**

Website: [fabrknt.com](https://fabrknt.com) · X: [@fabrknt](https://x.com/fabrknt)

---

## Fabrknt for HIP-3

For teams running Hyperliquid HIP-3 markets. → [fabrknt.com/hip3](https://fabrknt.com/hip3/index.html)

| Product | What it does |
|---------|-------------|
| **[HIP-3 Ops](https://fabrknt.com/hip3/ops/index.html)** | A self-hosted operations toolkit for HIP-3 markets |
| **[HL Price Guard](https://fabrknt.com/hip3/price-guard/index.html)** | Solidity library for HyperEVM apps that read Hyperliquid prices ([repo](https://github.com/fabrknt/hl-price-guard)) |
| **[HIP-3 Record](https://fabrknt.com/hip3/record/index.html)** | What HIP-3 operators did, from public data, including the [SK Hynix liquidation replay](https://fabrknt.com/hip3/record/replay/index.html) |
| **[Learn](https://fabrknt.com/hip3/learn/index.html)** | Courses on Hyperliquid's architecture, perps, HyperEVM development and vaults |
